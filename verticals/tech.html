What is Tech?

Tech measures a city's capacity for innovation and software development. It combines GitHub repository activity by location, engineering job postings, startup formation rates, and tech news mentions to show where the engineering energy is flowing.

Data Sources

  • GitHub API: Repository and contributor activity by city
  • Job Boards: Engineering positions posted in real time
  • GDELT Tech: Global news mentions of tech events and announcements
