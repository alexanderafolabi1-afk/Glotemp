# Glotemp – Global Mood & Tempo Map

Glotemp is a real-time emotional and economic tempo map of the world.  
The interface must be simple, visual, and cinematic — dark background, neon accents, animated gradient waves, and minimal text.  
The design style is “Spotify Wrapped × Weather Radar × Gen Z nightlife flyer”.

Core principles:
- Show, not tell.
- Big typography, lots of space.
- Abstract shapes, waves, and colour-coded mood states.
- No childish icons. No clutter.
- Smooth animations and transitions.

Technical requirements:
- Built with HTML, CSS, and JavaScript.
- SEO-friendly structure (semantic HTML, meta tags, OpenGraph).
- Integrate free APIs for weather, news, sports, events, and tourism.
- Integrate Claude API for mood synthesis.
- Human mood check-ins must update the city’s mood and tempo in real time.

Copilot should:
- Generate clean, modern, responsive UI.
- Use animated gradients and subtle motion.
- Keep code simple and readable.
- Avoid frameworks for now (no React).
